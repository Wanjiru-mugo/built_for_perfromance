[ Updating this page ]

Option A: key it in here
  1. Click + Add booking, + Hospitality or + Other spend and fill the form. It shows on this page straight away, saved in your browser only.
  2. Click Export data.json. A file downloads with old and new entries merged.
  3. Click Edit on GitHub, then Add file › Upload files, drop the new data.json in and commit. Everyone sees it within a minute or two.
Option B: edit the data file directly
  1. Open data.json on GitHub and click the pencil icon.
  2. Copy an existing entry block, paste it below, change the values. Category must be one of: Production, Kit & accessories, Hospitality, Other.
  3. Commit. The page rebuilds itself; charts and checks update automatically.
  4. Invoices: open the invoices folder on GitHub, Add file › Upload files, and name each PDF to match its entry, e.g. 2026-10-30-natalie.pdf. The Download button switches on automatically.
